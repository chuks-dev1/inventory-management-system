
# Inventory Management System

A Python-based inventory management application that uses SQLite
to manage products, track stock levels, and record sales.

## Features

- Add new products with prices and quantities
- View all products in the inventory
- Update product stock levels
- Search for products by name
- Record sales and automatically update stock
- Generate sales reports and calculate total revenue
- Identify products with low stock
- Store inventory and sales data in an SQLite database
- Preserve data between program sessions

## Technologies Used

- Python 3
- SQLite
- SQL
- Git and GitHub

## Requirements

- Python 3 installed on your computer
- Visual Studio Code or another Python-compatible editor

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Run the application:

   python main.py

The application creates its SQLite database automatically
when it starts.
